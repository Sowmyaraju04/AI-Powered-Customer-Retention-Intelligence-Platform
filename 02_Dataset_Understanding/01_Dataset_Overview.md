# Introduction

The AI-Powered Customer Retention Intelligence Platform is built using the Brazilian Olist E-Commerce Dataset. This dataset contains transactional, customer, product, seller, payment, delivery, and customer review information collected from a large Brazilian e-commerce marketplace.

Unlike a single flat dataset, the Olist dataset is a relational dataset consisting of multiple interconnected tables that collectively describe the complete customer purchase lifecycle.

The dataset provides sufficient historical information to perform descriptive analytics, diagnostic analytics, predictive modeling, and prescriptive analytics, making it an excellent choice for developing an enterprise-grade customer retention solution.

# Dataset Objective

The primary objective of this dataset is to provide comprehensive historical information about customer purchasing behavior.

Using this information, organizations can analyze customer behavior, purchasing trends, delivery performance, customer satisfaction, payment preferences, and revenue generation.

For this project, the dataset will be transformed into an AI-powered customer retention platform capable of identifying customers at risk of churn and recommending personalized retention strategies.

---

# Dataset Characteristics

The dataset contains multiple related tables representing different business entities.

These entities include:

- Customers
- Orders
- Order Items
- Products
- Sellers
- Payments
- Reviews
- Geolocation
- Product Category Translation

Each table contributes unique information that will later be integrated into a customer-level analytical data mart.

---

# Why This Dataset?

This dataset is particularly suitable for customer retention analysis because it captures the complete customer purchasing journey.

The available information enables the creation of meaningful behavioral features such as:

- Purchase Frequency
- Customer Recency
- Average Order Value
- Total Spending
- Delivery Performance
- Payment Behaviour
- Product Diversity
- Customer Satisfaction
- Purchase Seasonality

These features are commonly used in enterprise churn prediction models.
